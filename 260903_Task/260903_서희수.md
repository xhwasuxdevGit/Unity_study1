## 3. 확인해 본 것

### 1. `Destroy`에 넘길 시간 설정 및 이유

- `Life Seconds`는 `5`로 설정 함
- 현재 벨트의 길이는 `20(= 'Z Scale')`이고, 박스가 초당 움직이는 속도는 `4= ('Belt Speed')`로 설정 된 상태

- 벨트의 길이를 고려할 때 박스가 벨트위에서 사라지려면 박스는 `5초`뒤에 소멸해야 함 

### 2. 새로 생성된 상자(`BoxRoot`)와 저장해둔 상자(`Assets/Prefabs`)간 차이점과 그 이유

- `BoxRoot`를 통해 새로 만들어진 박스의 이름은 순서대로 Box(Clone) / BoxThin(Clone) / BoxWide(Clone)
- `Assets/Prefabs`에 저장해 둔 이름은 '(Clone)'표기가 없는 Box / BoxThin / BoxWide
- 이름이 달라지게된 이유는 `Prefab`을 통한 생성이기 때문
- `Assets/Prefabs`에 저장된 `Prefab`은 씬에 존재하는 개별 오브젝트가 아닌, 인스턴스 생성을 위한 조형틀(= `프리펩 에셋`)
- `BoxRoot` 통해 새로 만들어진 박스는 `Prefab`에서 정해진 설계도를 따라서 만들어진 개별 `프리팹 인스턴스`로, '(Clone)'이라는 표기가 붙은채로 생성됨

## 4. 확인 항목 자체 점검
- [x] 1. `Factory` 씬에 `Belt·Spawner·BoxRoot`가 있고 `Position·Rotation·Scale` 값이 표와 같습니다. 씬에 미리 놓인 상자는 없습니다
- [x] 2. `Box` 프리팹이 `Assets/Prefabs`에 저장되어 있고 자식으로 `Lid`와 `Tag`를 함께 담고 있습니다
- [x] 3. `BoxThin`과 `BoxWide`가 `Assets/Prefabs`에 프리팹으로 저장되어 있고, 각각의 루트 Scale과 Box Name 값이 표와 같습니다
- [x] 4. `_boxName`이 `[SerializeField] private` 필드이고 `BoxInfo`가 프리팹 셋에 모두 붙어 있습니다
- [x] 5. `BoxInfo`가 `Start`에서 올라온 것을, `OnDestroy`에서 사라지는 것을 각각 Console에 한 줄씩 남기며 두 줄에 상자 이름이 들어갑니다
- [x] 6. 프리팹 셋을 배열 필드 하나로 받고 있으며, 만들 때마다 다음 종류로 넘어가고 마지막 다음은 처음으로 돌아옵니다
- [x] 7. 상자를 만들 때 자리·회전·부모를 함께 넘기며, 자리는 `Spawner`가 있는 자리이고 부모는 `BoxRoot`입니다
- [x] 8. Space를 누른 그 프레임에만 상자가 하나 만들어집니다
- [x] 9. `Update`에서 시간을 쌓아 `_spawnInterval`마다 상자가 하나씩 자동으로 만들어지며, 매 프레임 만들어지지 않습니다
- [x] 10. `BeltMover`를 코드로 붙이고, 붙인 것을 받아 초당 이동 거리를 넘깁니다. `BeltMover`는 인스펙터로 붙어 있지 않습니다
- [x] 11. 상자가 벨트가 뻗은 방향으로 움직이며, `Time.deltaTime`이 초당으로 정한 값에만 곱해져 있습니다
- [x] 12. 만든 상자를 `_lifeSeconds` 뒤에 없애도록 예약하며, 그 값이 벨트 길이와 `Belt Speed`로 계산한 값과 크게 어긋나지 않습니다
- [x] 13. 압축본에 `Assets`·`ProjectSettings`·`Packages`와 `260903_본인이름.md`가 함께 들어 있고, 제출 문서의 네 개 섹션이 모두 채워져 있으며, 3번 섹션의 두 질문에 결과와 이유가 함께 적혀 있습니다
